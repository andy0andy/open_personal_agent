## 执行中发现、已处理的环境问题

- Docker Hub 不可达：镜像改经 `mirror.gcr.io`（备选 `docker.1ms.run`）与 `ghcr.io` 拉取。
- LiteLLM 导入时会去 GitHub 拉价格表：统一设置 `LITELLM_LOCAL_MODEL_COST_MAP=True`。
- 网关镜像内没有 wget：健康检查改用 python3。
- 本机 `~/.docker/config.json` 残留 Docker Desktop 的凭据程序配置：Makefile 让容器命令使用项目内的空配置（`deploy/docker-config/`）。
- 网络整体较慢（约 0.1～1 MB/s）：Ollama 镜像（arm64 约 2.7GB）与向量模型下载是最耗时的环节。
