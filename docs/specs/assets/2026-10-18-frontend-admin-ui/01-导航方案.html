导航怎么组织？

对话页仍然最常用，但要加上 模型 / 技能 / MCP / 配置 / 系统 这些页面。三种左侧栏的组织方式，点选你更喜欢的（可以说"A 但是……"）。

A

Hermes 原样：左侧纯导航

所有页面平铺在侧栏。会话列表挪进对话页内部，成为第二栏。和 Hermes 最像，但进对话要多一栏宽度。
