# 前端界面优化设计（2026-10-22）

- 状态：已审定（用户 2026-10-22 认可设计稿，并授权按最优解自行实施、最后汇报选择）
- 依据：[前端界面对比](../reviews/2026-10-20-前端界面与HermesAgent对比.md)第 4～6 节；设计稿（claude.ai 私有画布）[个人智能体界面优化设计稿](https://claude.ai/artifact/MyhPF2vW1daHTKZApHwSbz)：9 张画板——对话 ×3、设计规范、设置、模型、MCP、用量、技能
- 技术栈不变：React 19 + Vite + Tailwind 4 + assistant-ui 0.15.28，不新增依赖

## 1. 目的

日常使用里最常碰到的三类问题：浅色模式看不清；对话流里过程信息太吵（审批处理完仍是大卡片、工具名是英文、同一条命令出现两次）；状态看不出来（哪个会话在跑、在等审批、出了错；出错后不知道下一步）。另有两套视觉语言混用（对话页圆角、管理页直角）。这次只改界面，保留墨绿奶油的配色与"PERSONAL AGENT"字标。

## 2. 视觉规范

### 2.1 配色（两个底色推导其余，提示色按模式设定）

| | 深色 | 浅色 |
|---|---|---|
| 背景 / 正文（不变） | `#041c1c` / `#ffe6cb` | `#fbf7f0` / `#0b3b3a` |
| 琥珀（等你处理、品牌图标） | `#ffbd38` | `#b45309`（原 `#ffbd38`，对比度 1.56 → 4.70） |
| 成功 | `#4ade80` | `#1f7a4d`（原 1.63 → 4.98） |
| 危险 | `#ff5a5f`（原 `#fb2c36`，4.64 → 5.79） | `#b42318`（原 3.57 → 6.16） |
| 运行中（新） | `#6aa7f0` | `#1d5fa8` |
| 次要文字：正文混入背景的比例 | 62% | 76%（原 62%，3.88 → 5.74） |
| 提示色淡底：提示色混入背景的比例 | 10% | 7% |

- 推导出的颜色：卡片 4%、悬停 6%、muted 8%、强调底 11%、分隔线 15%、**输入框边框 35%（新）**、焦点框 45%。
- 淡底上的文字一律用正文色；提示色只用在圆点、图标、边框上（浅色琥珀在淡底上只有 4.30）。
- 代码高亮在浅色下的混色强度从 35% 提到 70%（提示色已经够深，混多一点才分得清）。
- **颜色只表示状态**：红 = 出错 / 放宽审批，琥珀 = 等你处理，绿 = 完成 / 已连接，蓝 = 运行中。模型能力标签（思考、看图、工具）、MCP 连接方式（本地进程、网络）用中性的带图标小标签。

### 2.2 字号、圆角、间距、动效

- 字号：空状态标题 24/600，页标题 17/600，区块标题 13/500 次要色，正文 15，次要说明 13，徽章与页脚 12，最小 11。
- 不用全大写、不加宽字距；**等宽字体只给数据**（模型名、命令、路径、设置键、数字）。"PERSONAL AGENT"字标是唯一例外。
- 圆角：卡片 12px，按钮与输入框 8px，徽章 6px，状态点、开关、胶囊全圆。
- 间距：4 / 8 / 12 / 16 / 24 / 32。
- 所有可点元素键盘聚焦时有可见焦点框（2px，焦点框色，偏移 2px）；系统开启"减少动效"时动画与过渡压到几乎为零。

### 2.3 共用组件

- 按钮三级：主按钮（正文色实心，每页最多一个）、次按钮（输入框边框 + 透明底）、文字按钮（次要色；危险操作用危险色）。去掉"奶油色实心直角块"、等宽大写的写法。
- 徽章：6px 圆角、强调底；"默认"用正文色实心小徽章；状态徽章 = 淡底 + 圆点 + 正文色文字。
- 开关：圆角胶囊，开时正文色底。
- 卡片（Panel）：12px 圆角，区块标题用正文字体 13/500 次要色。
- 页头：统一 60px，左边"标题 + 一行次要说明"，右边操作。
- 内容宽度：阅读类（对话、新会话）720px，管理类 880px。
- 侧栏：分"工作""管理"两组并显示组名；当前项强调底 + 中等粗细；窗口窄于 1280px 时只显示图标（悬停看名字）。

## 3. 对话界面

1. **会话列表**：每行 = 状态点（琥珀 待审批 / 蓝 运行中，带呼吸动画 / 红 出错 / 空闲不显示）+ 标题 + 右侧状态字或相对时间。顶部加"搜索会话标题"（纯前端过滤）。手动拖动排序保留，**不按日期分组**（与手动排序冲突）。有会话在跑或在等审批时，列表每 5 秒刷新一次。
2. **顶栏**：会话标题（17/600）+ 一行"N 轮"说明；右侧"文件"按钮（从输入框工具条挪来）与"更多"菜单（改名、删除，沿用会话列表的菜单）。权限档位与模型留在输入框工具条，不在顶栏重复。
3. **用户消息**：强调底 + 1px 分隔线色边框 + 正文色文字（原来是主色实心气泡）；仍右对齐。
4. **思考**：一行次要色小字"思考了 N 秒"（N 由事件时间戳算出；算不出时写"思考过程"），点开看内容。
5. **工具行**：
   - 一行 = 箭头 + 图标 + 中文动词 + 一段摘要（命令、文件路径、检索词）+ 用时 / 状态；次要色，悬停变正文色；
   - 同一轮内**相邻的工具调用合成一组**：一行摘要"读取了 1 个文件，运行了 1 条命令"，点开逐条显示；只有一个工具时直接显示那一行；
   - 执行命令展开后：`$ 命令`、退出码徽标（0 成功色淡底，非 0 危险色淡底）、输出（去掉末尾 `[Command … with exit code N]` 那一行），不再显示参数 JSON；
   - 子智能体单独成行，不并入工具组。
6. **审批卡片**（只在等你决定时出现）：
   - 琥珀淡底 + 整圈琥珀边框（不用左侧色条）；标题"要执行这条命令吗？"（执行命令）或"要调用 X 吗？"（其他工具）；命令或参数用等宽块显示；执行命令下面写一句"在本会话的目录里运行，能上网，也能读到项目里的大部分文件、连到本项目的数据库"（实施时更正：原写"能读写会话里的文件"，去掉沙箱后（D20、D23）命令碰得到的不止这些，不能说轻）；
   - 按钮右对齐：拒绝（文字按钮，Esc）· 回复一句话 · 修改后执行 · **同意**（主按钮，↵）；按键提示不计入按钮名称；焦点在卡片里时 Esc = 拒绝（实施时更正：原定"卡片出现时把焦点放到'同意'上"，整体审查发现用户正在输入框打字时，一个空格或回车就会变成"同意"——卡片不再抢焦点）；
   - **处理完以后收成一行，并入对应的工具行**：显示"已同意 / 已修改参数后执行 / 已拒绝 / 已回复：…"（沿用现有说法）；选了"修改后执行"时，实际执行的参数直接展开显示（标题"修改后的参数（实际执行的）"）；等待中途被停止的显示"已停止，未执行"；
   - 等待审批的工具不再单独显示一行（卡片已经代表它）。
7. **待办**：进行中的那一轮，待办显示在输入框上方："进度 2/4 · 正在：…"，可以展开看全部；对话流里的待办改成一行"待办 2/4"，点开看清单；运行已结束时没做完的项显示"未完成"，不再一直转圈。
8. **报错卡片**：危险色淡底 + 整圈危险色边框，标题是报错原文；按钮"重试这一句"（把这一轮的用户消息再发一次）、"换个模型再试"（选一个对话模型，改会话的模型后再发一次）、"复制详情"。额度用完时不给"重试这一句"。
9. **代码块**：超过 16 行先折叠，下面一个"展开全部 N 行"；回答还在输出时不着色，结束后再着色。
10. **输入框**：按会话保存草稿（浏览器本地，切走再回来还在，发送成功后清掉）；可以直接粘贴截图（粘贴板里的图片当作附件上传）。工具条：左边权限档位，右边"本会话 token · 上下文 N%"（N = 最近一次主智能体调用的输入 ÷ 模型最大输入，算不出时不显示）与模型选择。
11. **新会话落地页**（没选中会话时的 /chat）：图标 + "今天想做点什么？" + 一句说明 + 输入框（文字）+ 工具条（权限、模型）+ "最近的会话"前 3 个（带状态点）。发送时才建会话：建会话 → 按所选改模型与权限 → 发消息 → 打开这个会话。会话列表的"新建"仍然立刻建一个空会话（保持现有行为与测试）。

## 4. 管理页面

- **设置**：左侧分节导航（对话与模型、工作区、知识库、只读项、.workdata 文件，带项数，待重启的节带琥珀点）；页顶"N 项已保存，重启后生效 · 在终端执行 make restart"提示条（复制按钮）；"重启后生效"每节说一次，行内用"已改 · 待重启"徽章；被环境变量覆盖的项写"由 .env 的 XXX 指定"并带锁形图标；只读项每项写原因。
- **模型**：默认模型卡；列表每行 = 模型名（等宽）+"默认"实心徽章 + 一行资料 + 中性能力标签；"测试"结果直接显示在这一行下面；默认模型、在用的向量模型的删除按钮变淡并说明原因；页底一句"测试会真的调用一次模型，花几个 token"。
- **MCP**：每行 = 开关 + 服务名 + 连接方式标签 + 一行说明 + 状态（圆点 + 文字：已连接 · N 个工具 / 连接中… / 没有连上 / 已停用）；没连上时下面一条危险色淡底的原因（缺环境变量时写"在 .env 里设置，然后在终端执行 make restart"）；"测试"结果显示在行下。
- **技能**：开关胶囊；说明最多两行。
- **用量**：三张统计卡；每日柱状图铺满宽度、每天一根、输入与输出两色叠放（输入 = 正文色 70%，输出 = 成功色），左侧刻度、虚线网格、底部首中尾日期，悬停或聚焦一根柱子出浮层（日期、调用、输入、输出）；表格数字列右对齐、等宽。
- **知识库**：统一页头与内容宽度（其余不改）。

## 5. 后端改动

会话列表接口（`GET /api/threads`）的每个会话多带 `activity`：最近一次运行在排队或运行中为 `running`，在等审批为 `waiting`，失败为 `failed`，其余为空。只在列表里算（取每个会话最近一次运行），其他接口返回空。

实施时补了一处（整体审查发现）：执行命令的输出超过约 2000 字时，推送前的截断原来会切掉末尾的退出码那一行，界面看不出命令失败；现在截断时留下这一行（`agents/main_agent/runtime/translator.py`）。
