# M0 首跑 实施计划

> **给执行者：** 必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐个任务执行本计划。步骤用复选框（`- [ ]`）跟踪。开始任何任务前先读 `.claude/skills/dev-standards/SKILL.md`（任务 1 产出）。

**目标：** 交付一个能在浏览器里与云端任一模型版本多轮对话的最小版本；同时落地开发规范、项目骨架、compose 基础服务，并完成先行验证 V1～V6。

**架构：** 三大块同级、单向依赖：`frontend → backend → agents → config → common`。agents 用 deepagents 组装主智能体，经 LiteLLM 网关调用模型，对外只输出我们自己的事件流；backend（FastAPI）在后台执行运行、通过官方 SSE 推送事件、把合并后的事件写入界面历史表；frontend（React）用同一个事件处理器做实时显示和历史重放。PostgreSQL、LiteLLM 网关、Ollama（只做向量化）全部由 docker compose 管理。

**技术栈：** Python 3.12 + uv 0.11.7；deepagents 0.7.23、langchain 1.4.4、langgraph 1.2.14、langchain-litellm 0.11.0、FastAPI 0.143.0（原生 SSE）、psycopg 3.3.6、Alembic 1.20.0；LiteLLM 网关 v1.105.0；PostgreSQL 18 + pgvector 0.8.7；Ollama 0.40.3（`qwen3-embedding:0.6b`）；React 19.3 + Vite 8.3 + TypeScript 6.0 + Tailwind 4.3 + TanStack Query 5.104；Node 24.21.0 + pnpm 11.17.0；Podman 5.8（编排用 docker compose 5.0.1）。

**设计文档：** `docs/specs/2026-10-10-personal-agent-design.md`（本计划实现其第 21 节的 M0；执行者需同时阅读）。

> 本计划中的代码在写计划时已于临时目录实际运行验证：后端 23 个单元测试 + 16 个集成测试、前端 6 个测试，ruff / mypy 严格模式 / import-linter 全部通过。真实模型冒烟测试（任务 15）需要密钥，未运行。

## 全局约束

- 直接依赖一律写精确版本：Python 用 uv（`uv add 包==版本`，安装 `uv sync --locked`）；前端用 pnpm（`.npmrc` 设 `save-exact=true`，安装 `pnpm install --frozen-lockfile`）。（D12）
- 第三方服务一律由 `deploy/docker-compose.yml` 管理和构建，镜像写死版本。（D13）
- 依赖方向 `backend → agents → config → common`；backend 只使用 agents 各模块 `__init__.py` 公开的内容；由 import-linter 检查。（D6）
- 只为基础设施建可替换接口；deepagents 只出现在 `agents/main_agent/runtime/`。（D5）
- 顶层目录即 Python 包，不加前缀、不套 `src/`。
- 模型按具体版本登记（如 `claude-opus-5-5`），全部经 LiteLLM 网关调用；Ollama 只做向量化（`qwen3-embedding:0.6b`，1024 维）。（D1、D3、D15）
- 界面历史（`run_events` 表）与模型上下文（deepagents 对话存档）分开存。（D7）
- 只监听 `127.0.0.1`；所有表带 `user_id`。
- 注释与文档用中文，代码标识符用英文。
- 个人数据目录为 `workdata/`（环境变量 `WORKDATA_DIR`）。
- **当前不是 git 仓库：不执行任何 git 命令。** 每个任务以"检查点"结束（运行检查命令），代替提交。
- 网络：Docker Hub 不可达，Docker Hub 镜像经 `mirror.gcr.io` 拉取（备选 `docker.1ms.run`），其余来自 `ghcr.io`；LiteLLM 相关进程必须设置 `LITELLM_LOCAL_MODEL_COST_MAP=True`（否则导入时去 GitHub 拉价格表会卡住）。
- 前端命令一律通过 `make` 执行或先把 `~/.nvm/versions/node/v24.21.0/bin` 加到 `PATH` 前面（系统默认 Node 是 v18，不能用）。

## 重点关注

设计文档没有逐条写明、但最可能在实际使用中出问题的五类情况，以及固定它们的测试：

1. **中文输入法选字时按回车** → 只确认候选词，不发送消息。测试：任务 13 `keys.test.ts`。
2. **上一次运行没结束就在同一会话再次发送** → 返回 409，前端显示错误、不卡死。测试：任务 11 `test_only_one_active_run_per_thread`、任务 12 `test_second_active_run_is_rejected`。
3. **刷新页面或网络中断后重连** → 从断点续推、不重复不丢失；运行结束后再连能从界面历史补发。测试：任务 10 `test_subscribe_after_seq_skips_seen_events`、任务 12 `test_replay_after_finish_and_last_event_id`。
4. **密钥缺失、版本名写错、网关没启动** → 运行一定以看得懂的 `run.finished(failed)` 结束；模型列表接口返回 503；服务照常启动。测试：任务 6 契约测试、任务 8 `test_run_turns_model_failure_into_failed_event` 与 `test_build_agent_survives_unreachable_gateway`、任务 12 `test_model_failure_marks_run_failed` 与 `test_models_endpoint_returns_503_when_gateway_down`。
5. **服务在运行途中重启** → 该运行被标记为"服务重启中断"的失败，会话可以继续发送。测试：任务 11 `test_fail_unfinished`、任务 12 `test_unfinished_runs_fail_on_restart`。

````markdown
# 架构规范

> 适用于本项目全部代码。设计依据：`docs/specs/2026-10-10-personal-agent-design.md`。规范只在这里维护一份，`dev-standards` 技能只放要点并指向本文。

## 1. 总纲：底层解耦，功能内聚

- **底层解耦**：外部依赖（模型网关、沙箱、向量检索、文档解析、MCP、运行时队列等）都藏在我们自己定义的可替换接口后面；业务代码只认接口；"用哪个实现"只在组装根决定。
- **功能内聚**：一个能力模块把自己的接口、实现、数据访问、中间件、提供给智能体的工具放在一起；模块之间只调用对方公开的内容。
- **不过度包装**：LangChain 聊天模型、LangGraph 对话存档、deepagents 后端协议本身就是标准接口，直接使用。
- **只为基础设施建接口**：只有设计文档 4.1 所列的外部依赖才定义可替换接口，其他地方不预设抽象。

## 2. 三大块与依赖方向

```
frontend ──(HTTP 接口 + 推送协议)──→ backend ──→ agents ──→ config ──→ common
```

| 目录 | 职责 | 允许依赖 |
|---|---|---|
| `agents/` | 智能体能力；可脱离 HTTP 独立运行 | `config`、`common` |
| `backend/` | 把 agents 的能力通过 HTTP 与推送提供出去；运行调度 | `agents` 的公开内容、`config`、`common` |
| `frontend/` | 浏览器界面 | 只通过 `/api` 与推送协议访问 backend |
| `config/` | 读取配置的代码 + 所有可编辑的配置文件 | `common` |
| `common/` | 与业务无关的基础设施：数据库连接池、错误类型、ID | 无 |

依赖方向由 import-linter 强制（`pyproject.toml` 的 `[tool.importlinter]`），`make check` 会检查：
1. 分层：`backend → agents → config → common`，不得反向。
2. `backend` 不得引用 agents 的内部实现模块（如 `agents.main_agent.runtime.translator`），只用各模块 `__init__.py` 导出的内容。

## 3. 模块结构模板

### agents 能力模块（`agents/main_agent/<能力>/`）

| 文件 | 内容 |
|---|---|
| `__init__.py` | 对外公开的内容（其他模块与 backend 只能从这里导入） |
| `base.py` | 可替换接口（`typing.Protocol`）与数据结构（仅基础设施类能力需要） |
| `<实现名>.py` | 接口的具体实现，如 `litellm_proxy.py` |
| `tools.py` | 提供给智能体的工具 |
| `repo.py` | 本模块拥有的表的数据访问 |

`agents/main_agent/bootstrap.py` 是组装根：按 `config/app.yaml` 的 `adapters` 选择实现并装配，产出 `MainAgent`。

### backend 功能模块（`backend/<功能>/`）

| 文件 | 内容 |
|---|---|
| `schemas.py` | 接口与数据库之间的数据结构（pydantic） |
| `repo.py` | 数据访问（psycopg + 原生 SQL） |
| `manager.py` 等 | 业务流程 |
| `__init__.py` | 对外公开的内容 |

路由统一放在 `backend/api/`；服务对象在启动时装配到 `app.state.services`（见 `backend/api/deps.py`）。

## 4. 可替换接口的写法

```python
# agents/main_agent/<能力>/base.py —— 接口
class XxxGateway(Protocol):
    async def do(self, ...) -> Result: ...

# agents/main_agent/<能力>/<实现名>.py —— 实现（不继承接口，按结构匹配）
class FooXxxGateway:
    async def do(self, ...) -> Result: ...

# agents/main_agent/bootstrap.py —— 登记
_XXX: dict[str, Callable[[Settings], XxxGateway]] = {"foo": lambda s: FooXxxGateway(...)}

# agents/tests/contracts/test_xxx_contract.py —— 契约测试
IMPLEMENTATIONS = [make_foo]          # 新实现加进这个列表，必须跑通同一套测试
```

新增实现 = 写实现类 + 在组装根登记 + 加进契约测试 + 在 `config/app.yaml` 选中。

## 5. 数据归属与迁移

- 每张表归属一个模块，只有该模块的 `repo.py` 读写它。
- 表结构变更统一用 Alembic，脚本放 `backend/migrations/versions/`，**一律写原生 SQL**；文件名带归属模块前缀，如 `0002_agents_knowledge.py`。
- deepagents 的对话存档表由 `AsyncPostgresSaver.setup()` 自行创建，不写迁移。
- 所有表带 `user_id`（v1 固定 `'me'`）。

## 6. 配置、密钥与第三方服务

- 可编辑配置都在 `config/`：`app.yaml`（应用）、`models.yaml`（网关模型版本清单）。
- 密钥只放根目录 `.env`（不进版本库）；模板是 `.env.example`。
- **第三方服务一律在 `deploy/docker-compose.yml` 中定义**，镜像写死版本；当前网络访问不了 Docker Hub，经 `mirror.gcr.io` 拉取。
- 个人数据放 `workdata/`（不进版本库、需要备份）；数据库数据在 Docker 数据卷中。

## 7. 新增功能的步骤清单

**新增 agents 能力模块**：建 `agents/main_agent/<能力>/` → 需要外部依赖时先写 `base.py` 接口与契约测试 → 写实现 → 在 `bootstrap.py` 装配 → 只通过 `__init__.py` 对外公开 → 如需建表，按第 5 节写迁移。

**新增接口路由**：在对应 backend 功能模块写 `schemas.py` / `repo.py` / 业务 → 在 `backend/api/` 加路由 → 可预期错误抛 `common.errors` 中的类型（统一映射为 404 / 409 / 503）→ 流式接口的存在性检查放在依赖里（推送开始后无法再返回 404）。

**新增前端功能**：在 `frontend/src/features/<功能>/` 下建组件；接口调用加到 `src/api/client.ts`；类型加到 `src/api/types.ts`；纯逻辑（如事件处理器）必须有单元测试。

**新增第三方服务**：加进 `deploy/docker-compose.yml`（固定版本、只监听 `127.0.0.1`）→ 在 `Makefile` 补命令 → 写决策记录。
````

```markdown
# 编码规范

> 以官方规范为准，代码尽量精简，与项目架构对齐（见 `architecture.md`）。

## 1. 通用

## 2. Python

- 依据：PEP 8（风格）、PEP 257（文档字符串）、PEP 484 与 typing 官方文档（类型）。
- 工具：`ruff format` 统一格式；`ruff check` 规则见 `pyproject.toml`；`mypy --strict`（含 pydantic 插件）。行宽 100。
```

```markdown
# 测试规范

## 1. 分层与命令

| 层次 | 标记 | 命令 | 需要什么 |
|---|---|---|---|
| 单元测试（含契约测试、离线先行验证） | 无 | `make test`（`make check` 也会跑） | 什么都不需要 |
| 集成测试 | `@pytest.mark.integration` | `make test-int` | 自动启动 compose `test` 配置组的 `postgres-test`（端口 55432） |
| 真实模型冒烟测试 | `@pytest.mark.live` | `make smoke` | `make infra-up` + `.env` 中的模型密钥；会产生少量费用 |
| 前端单元测试 | — | `cd frontend && pnpm test` | 什么都不需要 |

默认 `pytest` 只跑单元测试（`pyproject.toml` 的 `addopts` 排除了 integration 与 live）。

## 2. 写测试的规则

- 先写测试、看它失败，再写实现。
- **不调用真实模型**：用 `agents/tests/fakes.py` 里的 `ScriptedChatModel`（按剧本回复，支持工具调用与逐字流式）、`FailingChatModel`、`FakeGateway`。LangChain 自带的 `GenericFakeChatModel` 在流式模式下不支持工具调用，不要用。
- **契约测试**：每个可替换接口在 `agents/tests/contracts/` 下有一套测试，用 `IMPLEMENTATIONS` 列表参数化；新实现必须加进列表并跑通。
- **数据库测试**：使用根目录 `conftest.py` 的 `db` 夹具（每个测试前清空 backend 的表）；不要连接开发库。
- **接口测试**：使用 `backend/tests/conftest.py` 的 `make_client(模型)`，它直接装配服务对象，不走 `lifespan`。
- **离线先行验证**放在 `agents/tests/spikes/`：用于固定"第三方库的关键行为"，库升级后它们会第一时间报警。
```

```python
"""ID 生成。"""

import secrets
import uuid


def new_id() -> uuid.UUID:
    """通用主键。"""
    return uuid.uuid4()


def short_id(prefix: str = "c_") -> str:
    """会话短 ID：前缀 + 8 位十六进制，便于模型在路径中准确引用。"""
    return f"{prefix}{secrets.token_hex(4)}"
```

```python
ROOT_DIR = CONFIG_DIR.parent


class AdaptersConfig(BaseModel):
    """各可替换接口选用的具体实现名。"""

    """主智能体配置。"""

    default_model: str
    system_prompt_file: Path = ROOT_DIR / "agents" / "prompts" / "system.md"


class Settings(BaseSettings):
    """全局配置。

    字段名即环境变量名（不区分大小写）；嵌套字段用双下划线，如 AGENT__DEFAULT_MODEL。
    """

        env_file=ROOT_DIR / ".env",
        env_nested_delimiter="__",
        extra="ignore",
        yaml_file=CONFIG_DIR / "app.yaml",
        yaml_file_encoding="utf-8",
    )

    litellm_base_url: str = "http://127.0.0.1:4000"
    litellm_master_key: SecretStr
    workdata_dir: Path = ROOT_DIR / "workdata"
    adapters: AdaptersConfig = AdaptersConfig()
    agent: AgentConfig

    @classmethod
    def settings_customise_sources(
        cls,
        settings_cls: type[BaseSettings],
        init_settings: PydanticBaseSettingsSource,
        env_settings: PydanticBaseSettingsSource,
        dotenv_settings: PydanticBaseSettingsSource,
        file_secret_settings: PydanticBaseSettingsSource,
    ) -> tuple[PydanticBaseSettingsSource, ...]:
        # 优先级从高到低：构造参数 > 环境变量 > .env > app.yaml
        return (
            init_settings,
            env_settings,
            dotenv_settings,
            YamlConfigSettingsSource(settings_cls),
            file_secret_settings,
        )


@lru_cache

    """读取并缓存配置；测试中用 get_settings.cache_clear() 重新读取。"""
```

```python
        context.configure(connection=connection, target_metadata=None)
```

```python
"""模型网关实现：LiteLLM 网关，智能体侧用 langchain-litellm 的 ChatLiteLLM 调用。"""

from typing import Any

import httpx
from langchain_core.language_models import BaseChatModel
from langchain_litellm import ChatLiteLLM

from agents.main_agent.models.base import ModelInfo
from common.errors import UpstreamError


class LiteLLMProxyGateway:
    """通过 LiteLLM 网关访问所有模型版本。"""

    def __init__(
        self, base_url: str, api_key: str, *, transport: httpx.AsyncBaseTransport | None = None
    ) -> None:
        self._base_url = base_url.rstrip("/")
        self._api_key = api_key
        self._transport = transport  # 仅测试时注入
        self._known: dict[str, ModelInfo] = {}

    async def list_models(self) -> list[ModelInfo]:
        try:
            async with httpx.AsyncClient(
                base_url=self._base_url, transport=self._transport, timeout=10
            ) as client:
                resp = await client.get(
                    "/model/info", headers={"Authorization": f"Bearer {self._api_key}"}
                )
                resp.raise_for_status()
        except httpx.HTTPError as exc:
            raise UpstreamError(f"模型网关不可用：{exc}") from exc
        models = [_to_model_info(item) for item in resp.json()["data"]]
        self._known = {model.name: model for model in models}
        return models

    def chat_model(self, name: str) -> BaseChatModel:
        info = self._known.get(name)
        # deepagents 按 profile 里的上下文长度决定何时压缩；网关信息缺失时交给它的默认值
        profile = None
        if info and info.max_input_tokens:
            profile = {"max_input_tokens": info.max_input_tokens}
        return ChatLiteLLM(
            model=f"litellm_proxy/{name}",
            api_base=self._base_url,
            api_key=self._api_key,
            streaming=True,
            stream_options={"include_usage": True},
            profile=profile,
        )


def _to_model_info(item: dict[str, Any]) -> ModelInfo:
    info = item.get("model_info") or {}
    return ModelInfo(
        name=item["model_name"],
        mode=info.get("mode") or "chat",
        max_input_tokens=info.get("max_input_tokens"),
        input_cost_per_token=info.get("input_cost_per_token"),
        output_cost_per_token=info.get("output_cost_per_token"),
        supports_reasoning=bool(info.get("supports_reasoning")),
        supports_vision=bool(info.get("supports_vision")),
    )
```

```python
"""智能体对外推送的事件协议（M0 核心子集）。backend 原样转发，只在外层加序号等信封字段。"""

from typing import Annotated, Any, Literal

from pydantic import BaseModel, Field, TypeAdapter


class _BaseEvent(BaseModel):
    agent_path: list[str] = Field(default_factory=lambda: ["main"])


class RunStarted(_BaseEvent):
    type: Literal["run.started"] = "run.started"
    model: str


class MessageDelta(_BaseEvent):
    type: Literal["message.delta"] = "message.delta"
    message_id: str
    text: str


class ToolStarted(_BaseEvent):
    type: Literal["tool.started"] = "tool.started"
    call_id: str
    name: str
    args: dict[str, Any]


class ToolFinished(_BaseEvent):
    type: Literal["tool.finished"] = "tool.finished"
    call_id: str
    name: str
    status: Literal["success", "error"]
    output: str


class RunFinished(_BaseEvent):
    type: Literal["run.finished"] = "run.finished"
    status: Literal["completed", "failed"]
    error: str | None = None


type Event = Annotated[
    RunStarted | MessageDelta | ToolStarted | ToolFinished | RunFinished,
    Field(discriminator="type"),
]

EVENT_ADAPTER: TypeAdapter[Event] = TypeAdapter(Event)
```

`agents/main_agent/runtime/translator.py`：

```python
"""把 deepagents（LangGraph v2 输出流）的原始片段翻译成我们的事件。

- 回答文字取自 `messages` 模式的 AIMessageChunk（逐字）。
- 工具开始 / 结束取自 `updates` 模式里 `model` / `tools` 节点的完整消息
  （`messages` 模式里的工具参数是分片的，不适合直接展示）。
"""

from collections.abc import Iterator
from typing import Any

from langchain_core.messages import AIMessage, AIMessageChunk, ToolMessage
from langgraph.types import StreamPart

from agents.main_agent.runtime.events import Event, MessageDelta, ToolFinished, ToolStarted

TOOL_OUTPUT_LIMIT = 2000


def translate(part: StreamPart[Any, Any]) -> Iterator[Event]:
    """翻译一个输出流片段；M0 只翻译主智能体（ns 为空），子智能体归属在 M1 处理。"""
    if part["ns"]:
        return
    if part["type"] == "messages":
        chunk, _metadata = part["data"]
        if isinstance(chunk, AIMessageChunk) and (text := _text_of(chunk.content)):
            yield MessageDelta(message_id=chunk.id or "", text=text)
    elif part["type"] == "updates":
        yield from _translate_updates(part["data"])


def _translate_updates(data: dict[str, Any]) -> Iterator[Event]:
    for node, update in data.items():
        if node not in ("model", "tools") or not isinstance(update, dict):
            continue
        for message in update.get("messages", []):
            if isinstance(message, AIMessage):
                for call in message.tool_calls:
                    yield ToolStarted(
                        call_id=call["id"] or "", name=call["name"], args=call["args"]
                    )
            elif isinstance(message, ToolMessage):
                yield ToolFinished(
                    call_id=message.tool_call_id,
                    name=message.name or "",
                    status="error" if message.status == "error" else "success",
                    output=_text_of(message.content)[:TOOL_OUTPUT_LIMIT],
                )


def _text_of(content: str | list[Any]) -> str:
    """取出消息内容中的纯文本；内容块形式（如 Anthropic）只拼接 text 块。"""
    if isinstance(content, str):
        return content
    return "".join(
        block.get("text", "")
        for block in content
        if isinstance(block, dict) and block.get("type") == "text"
    )
```

```python
import json
from collections.abc import Iterator, Sequence
from typing import Any

from langchain_core.callbacks import CallbackManagerForLLMRun
from langchain_core.language_models import BaseChatModel
from langchain_core.messages import AIMessage, AIMessageChunk, BaseMessage
from langchain_core.outputs import ChatGeneration, ChatGenerationChunk, ChatResult

from agents.main_agent.models import ModelInfo
from common.errors import UpstreamError


class ScriptedChatModel(BaseChatModel):
    """按剧本依次返回预设回复；支持工具调用与逐字流式输出。

    LangChain 自带的 GenericFakeChatModel 在流式模式下不支持工具调用，所以自写这个替身。
    """

    responses: list[AIMessage]
    cursor: int = 0

    @property
    def _llm_type(self) -> str:
        return "scripted"

    def bind_tools(self, tools: Sequence[Any], **kwargs: Any) -> "ScriptedChatModel":
        return self

    def _next(self) -> AIMessage:
        message = self.responses[self.cursor]
        self.cursor += 1
        return message

    def _generate(
        self,
        messages: list[BaseMessage],
        stop: list[str] | None = None,
        run_manager: CallbackManagerForLLMRun | None = None,
        **kwargs: Any,
    ) -> ChatResult:
        return ChatResult(generations=[ChatGeneration(message=self._next())])

    def _stream(
        self,
        messages: list[BaseMessage],
        stop: list[str] | None = None,
        run_manager: CallbackManagerForLLMRun | None = None,
        **kwargs: Any,
    ) -> Iterator[ChatGenerationChunk]:
        message = self._next()
        text = message.content if isinstance(message.content, str) else ""
        for char in text:
            yield ChatGenerationChunk(message=AIMessageChunk(content=char))
        if message.tool_calls:
            chunks = [
                {"name": c["name"], "args": json.dumps(c["args"]), "id": c["id"], "index": i}
                for i, c in enumerate(message.tool_calls)
            ]
            yield ChatGenerationChunk(message=AIMessageChunk(content="", tool_call_chunks=chunks))


class FailingChatModel(ScriptedChatModel):
```

```python
"""主智能体总入口：按模型版本组装 deepagents，运行并输出我们自己的事件流。"""

from collections.abc import AsyncIterator
from typing import Any

from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware
from langgraph.checkpoint.base import BaseCheckpointSaver
from langgraph.graph.state import CompiledStateGraph

from agents.main_agent.models import ModelGateway
from agents.main_agent.runtime.events import Event, RunFinished, RunStarted
from agents.main_agent.runtime.translator import translate


class MainAgent:
    """backend 只通过它与智能体交互。"""

    def __init__(
        self, *, gateway: ModelGateway, checkpointer: BaseCheckpointSaver[Any], system_prompt: str
    ) -> None:
        self.models = gateway
        self._checkpointer = checkpointer
        self._system_prompt = system_prompt
        self._graphs: dict[str, CompiledStateGraph[Any, Any, Any, Any]] = {}

    async def run(
        self, *, thread_id: str, run_id: str, message: str, model: str
    ) -> AsyncIterator[Event]:
        """执行一次运行。任何异常都转成 `run.finished(failed)`，不向调用方抛出。"""
        yield RunStarted(model=model)
        try:
            graph = self._graph_for(model)
            async for part in graph.astream(
                {"messages": [{"role": "user", "content": message}]},
                {"configurable": {"thread_id": thread_id}, "metadata": {"run_id": run_id}},
                stream_mode=["messages", "updates"],
                subgraphs=True,
                version="v2",
            ):
                for event in translate(part):
                    yield event
        except Exception as exc:  # noqa: BLE001 - 运行边界：模型 / 工具链路的任何失败都要变成失败事件
            yield RunFinished(status="failed", error=f"{type(exc).__name__}: {exc}")
            return
        yield RunFinished(status="completed")

    def _graph_for(self, model: str) -> CompiledStateGraph[Any, Any, Any, Any]:
        """按模型版本缓存组装好的智能体，避免每次请求重新组装。"""
        if model not in self._graphs:
            self._graphs[model] = create_deep_agent(
                model=self.models.chat_model(model),
                system_prompt=self._system_prompt,
                middleware=[TodoListMiddleware()],
                checkpointer=self._checkpointer,
            )
        return self._graphs[model]
```

```python
"""运行时替换点②：事件总线。v1 用进程内存实现；多进程时换成 PostgreSQL 通知或 Redis 消息流。"""

import asyncio
from collections.abc import AsyncIterator
from functools import partial
from typing import Protocol

from backend.runtime.envelope import EventEnvelope


class EventBus(Protocol):
    """按运行发布事件；订阅者可从任意序号之后开始接收，直到运行关闭。"""

    def has(self, run_id: str) -> bool: ...

    def open(self, run_id: str) -> None: ...

    async def publish(self, run_id: str, event: EventEnvelope) -> None: ...

    async def close(self, run_id: str) -> None: ...

    def subscribe(self, run_id: str, after_seq: int = 0) -> AsyncIterator[EventEnvelope]: ...


class InMemoryEventBus:
    """单进程事件总线：每个运行一个事件列表；运行关闭后保留一段时间供断线重连补发。"""

    def __init__(self, *, retain_seconds: float = 60.0) -> None:
        self._events: dict[str, list[EventEnvelope]] = {}
        self._closed: set[str] = set()
        self._changed = asyncio.Condition()
        self._retain_seconds = retain_seconds

    def has(self, run_id: str) -> bool:
        return run_id in self._events

    def open(self, run_id: str) -> None:
        self._events[run_id] = []

    async def publish(self, run_id: str, event: EventEnvelope) -> None:
        async with self._changed:
            self._events[run_id].append(event)
            self._changed.notify_all()

    async def close(self, run_id: str) -> None:
        async with self._changed:
            self._closed.add(run_id)
            self._changed.notify_all()
        asyncio.get_running_loop().call_later(self._retain_seconds, self._forget, run_id)

    async def subscribe(self, run_id: str, after_seq: int = 0) -> AsyncIterator[EventEnvelope]:
        sent = after_seq
        while True:
            async with self._changed:
                await self._changed.wait_for(partial(self._ready, run_id, sent))
                pending = [e for e in self._events.get(run_id, []) if e.seq > sent]
                finished = run_id in self._closed or run_id not in self._events
            for event in pending:
                yield event
                sent = event.seq
            if finished and not pending:
                return

    def _ready(self, run_id: str, sent: int) -> bool:
        events = self._events.get(run_id)
        return events is None or run_id in self._closed or (bool(events) and events[-1].seq > sent)

    def _forget(self, run_id: str) -> None:
        self._events.pop(run_id, None)
        self._closed.discard(run_id)
```

```python
from backend.runtime import EventEnvelope


def compact(events: list[EventEnvelope]) -> list[EventEnvelope]:
    """合并相邻且属于同一条回答的 message.delta；合并后保留该组第一个事件的序号。"""
    result: list[EventEnvelope] = []
    for event in events:
        previous = result[-1] if result else None
        if (
            previous is not None
            and event.type == previous.type == "message.delta"
            and event.data["message_id"] == previous.data["message_id"]
        ):
            merged = {**previous.data, "text": previous.data["text"] + event.data["text"]}
            result[-1] = previous.model_copy(update={"data": merged})
        else:
            result.append(event)
    return result
```

```python
"""运行与运行事件的数据访问。"""

from uuid import UUID

from psycopg.errors import UniqueViolation
from psycopg.types.json import Jsonb

from backend.runs.schemas import RunHistory, RunRecord
from backend.runtime import EventEnvelope
from common.db import Pool
from common.errors import ConflictError, NotFoundError
from common.ids import new_id

_COLUMNS = "id, thread_id, status, model, input->>'message' AS message, error, created_at"


class RunRepo:
    def __init__(self, pool: Pool) -> None:
        self._pool = pool

    async def create(self, *, thread_id: UUID, model: str, message: str) -> RunRecord:
        """新建一条运行中的记录；同一会话已有进行中的运行时抛 ConflictError（由唯一索引保证）。"""
        try:
            async with self._pool.connection() as conn:
                cur = await conn.execute(
                    "INSERT INTO runs (id, thread_id, status, model, input) "
                    f"VALUES (%s, %s, 'running', %s, %s) RETURNING {_COLUMNS}",
                    (new_id(), thread_id, model, Jsonb({"message": message})),
                )
                row = await cur.fetchone()
        except UniqueViolation as exc:
            raise ConflictError("该会话已有进行中的运行，请等待它结束") from exc
        assert row is not None  # INSERT ... RETURNING 必有一行
        return RunRecord.model_validate(row)

    async def get(self, run_id: UUID) -> RunRecord:
        async with self._pool.connection() as conn:
            cur = await conn.execute(f"SELECT {_COLUMNS} FROM runs WHERE id = %s", (run_id,))
            row = await cur.fetchone()
        if row is None:
            raise NotFoundError(f"运行不存在：{run_id}")
        return RunRecord.model_validate(row)

    async def finish(self, run_id: UUID, *, status: str, error: str | None) -> None:
        async with self._pool.connection() as conn:
            await conn.execute(
                "UPDATE runs SET status = %s, error = %s, finished_at = now() WHERE id = %s",
                (status, error, run_id),
            )

    async def add_events(self, run_id: UUID, events: list[EventEnvelope]) -> None:
        if not events:
            return
        async with self._pool.connection() as conn, conn.cursor() as cur:
            await cur.executemany(
                "INSERT INTO run_events (run_id, seq, type, payload) VALUES (%s, %s, %s, %s)",
                [(run_id, e.seq, e.type, Jsonb(e.model_dump(mode="json"))) for e in events],
            )

    async def events(self, run_id: UUID, *, after_seq: int = 0) -> list[EventEnvelope]:
        async with self._pool.connection() as conn:
            cur = await conn.execute(
                "SELECT payload FROM run_events WHERE run_id = %s AND seq > %s ORDER BY seq",
                (run_id, after_seq),
            )
            rows = await cur.fetchall()
        return [EventEnvelope.model_validate(row["payload"]) for row in rows]

    async def history(self, thread_id: UUID) -> list[RunHistory]:
        """会话的界面历史：按时间顺序的每次运行及其已存事件。"""
        async with self._pool.connection() as conn:
            cur = await conn.execute(
                f"SELECT {_COLUMNS} FROM runs WHERE thread_id = %s ORDER BY created_at",
                (thread_id,),
            )
            runs = await cur.fetchall()
            cur = await conn.execute(
                "SELECT e.run_id, e.payload FROM run_events e JOIN runs r ON r.id = e.run_id "
                "WHERE r.thread_id = %s ORDER BY e.run_id, e.seq",
                (thread_id,),
            )
            event_rows = await cur.fetchall()
        events: dict[UUID, list[EventEnvelope]] = {}
        for row in event_rows:
            events.setdefault(row["run_id"], []).append(
                EventEnvelope.model_validate(row["payload"])
            )
        return [RunHistory(**run, events=events.get(run["id"], [])) for run in runs]

    async def fail_unfinished(self) -> int:
        """服务启动时调用：把上次进程退出时未跑完的运行标记为失败，返回处理条数。"""
        async with self._pool.connection() as conn:
            cur = await conn.execute(
                "UPDATE runs SET status = 'failed', error = '服务重启中断', finished_at = now() "
                "WHERE status IN ('queued', 'running')"
            )
            return cur.rowcount
```

```python
"""运行管理：在后台执行运行，把事件推给事件总线，结束后写入界面历史。"""

import asyncio
from collections.abc import AsyncIterator
from uuid import UUID

from agents.main_agent.runtime import Event, MainAgent, RunFinished
from backend.runs.compaction import compact
from backend.runs.repo import RunRepo
from backend.runs.schemas import RunCreate, RunRecord
from backend.runtime import EventBus, EventEnvelope
from backend.threads import ThreadRepo


class RunManager:
    def __init__(
        self, *, runs: RunRepo, threads: ThreadRepo, agent: MainAgent, bus: EventBus
    ) -> None:
        self._runs = runs
        self._threads = threads
        self._agent = agent
        self._bus = bus
        self._tasks: set[asyncio.Task[None]] = set()

    async def start(self, thread_id: UUID, body: RunCreate) -> RunRecord:
        """发起一次运行并立即返回；运行在后台进行。"""
        thread = await self._threads.get(thread_id)
        run = await self._runs.create(
            thread_id=thread.id, model=body.model or thread.model, message=body.message
        )
        await self._threads.touch(thread.id, first_message=body.message)
        self._bus.open(str(run.id))
        task = asyncio.create_task(self._execute(run))
        self._tasks.add(task)  # 持有引用，防止任务被垃圾回收
        task.add_done_callback(self._tasks.discard)
        return run

    async def stream(self, run_id: UUID, *, after_seq: int = 0) -> AsyncIterator[EventEnvelope]:
        """推送某次运行在 after_seq 之后的事件：运行还在内存中则实时推送，否则从界面历史补发。"""
        key = str(run_id)
        if self._bus.has(key):
            async for event in self._bus.subscribe(key, after_seq):
                yield event
            return
        for event in await self._runs.events(run_id, after_seq=after_seq):
            yield event

    async def _execute(self, run: RunRecord) -> None:
        run_id = str(run.id)
        published: list[EventEnvelope] = []
        last: Event | None = None
        try:
            async for event in self._agent.run(
                thread_id=str(run.thread_id), run_id=run_id, message=run.message, model=run.model
            ):
                last = event
                published.append(await self._publish(run_id, event, seq=len(published) + 1))
        finally:
            # 保证每次运行都以 run.finished 结束，前端据此关闭推送连接
            if not isinstance(last, RunFinished):
                last = RunFinished(status="failed", error="运行意外中止")
                published.append(await self._publish(run_id, last, seq=len(published) + 1))
            await self._runs.add_events(run.id, compact(published))
            await self._runs.finish(run.id, status=last.status, error=last.error)
            await self._bus.close(run_id)

    async def _publish(self, run_id: str, event: Event, *, seq: int) -> EventEnvelope:
        envelope = EventEnvelope.wrap(event, seq=seq, run_id=run_id)
        await self._bus.publish(run_id, envelope)
        return envelope
```

```python
    for error_type, status_code in _STATUS.items():
        app.add_exception_handler(error_type, _respond_with(status_code))


def _respond_with(status_code: int) -> Callable[[Request, Exception], Awaitable[JSONResponse]]:
```

```ts
import type { EventEnvelope } from "./types";

/** 订阅一次运行的推送；收到 run.finished 后主动关闭，避免浏览器自动重连。 */
export function subscribeRun(runId: string, onEvent: (event: EventEnvelope) => void): () => void {
  const source = new EventSource(`/api/runs/${runId}/events`);
  source.onmessage = (message: MessageEvent<string>) => {
    const event = JSON.parse(message.data) as EventEnvelope;
    onEvent(event);
    if (event.type === "run.finished") source.close();
  };
  return () => source.close();
}
```

```ts
import type { EventEnvelope, RunHistory } from "../../api/types";

export type ChatItem =
  | { kind: "user"; id: string; text: string }
  | { kind: "assistant"; id: string; text: string }
  | {
      kind: "tool";
      id: string;
      name: string;
      args: Record<string, unknown>;
      status: "running" | "success" | "error";
      output: string;
    }
  | { kind: "error"; id: string; text: string };

export interface ChatState {
  items: ChatItem[];
  running: boolean;
}

export const emptyChat: ChatState = { items: [], running: false };

export function addUserMessage(state: ChatState, id: string, text: string): ChatState {
  return { ...state, items: [...state.items, { kind: "user", id, text }] };
}

export function addError(state: ChatState, id: string, text: string): ChatState {
  return { items: [...state.items, { kind: "error", id, text }], running: false };
}

/** 事件处理器：输入当前状态和一个事件，输出新状态。实时推送与历史重放共用。 */
export function applyEvent(state: ChatState, event: EventEnvelope): ChatState {
  switch (event.type) {
    case "run.started":
      return { ...state, running: true };
    case "message.delta": {
      const id = `msg-${event.data.message_id}`;
      const last = state.items.at(-1);
      if (last?.kind === "assistant" && last.id === id) {
        const merged = { ...last, text: last.text + event.data.text };
        return { ...state, items: [...state.items.slice(0, -1), merged] };
      }
      return {
        ...state,
        items: [...state.items, { kind: "assistant", id, text: event.data.text }],
      };
    }
    case "tool.started":
      return {
        ...state,
        items: [
          ...state.items,
          {
            kind: "tool",
            id: `tool-${event.data.call_id}`,
            name: event.data.name,
            args: event.data.args,
            status: "running",
            output: "",
          },
        ],
      };
    case "tool.finished": {
      const id = `tool-${event.data.call_id}`;
      return {
        ...state,
        items: state.items.map((item) =>
          item.kind === "tool" && item.id === id
            ? { ...item, status: event.data.status, output: event.data.output }
            : item,
        ),
      };
    }
    case "run.finished":
      return event.data.status === "failed"
        ? addError(state, `err-${event.run_id}`, event.data.error ?? "运行失败")
        : { ...state, running: false };
  }
}

/** 由界面历史（每次运行的用户消息 + 已存事件）重建对话状态。 */
export function chatFromHistory(runs: RunHistory[]): ChatState {
  return runs.reduce(
    (state, run) =>
      run.events.reduce(applyEvent, addUserMessage(state, `user-${run.id}`, run.message)),
    emptyChat,
  );
}
```

```tsx
import { useQuery, useQueryClient } from "@tanstack/react-query";
import { useEffect, useState } from "react";
import { api } from "../../api/client";
import { subscribeRun } from "../../api/events";
import type { RunHistory, Thread } from "../../api/types";
import { ModelSelect } from "../models/ModelSelect";
import { Composer } from "./Composer";
import { MessageList } from "./MessageList";
import { addError, addUserMessage, applyEvent, chatFromHistory, type ChatState } from "./reducer";

const ACTIVE = new Set(["queued", "running"]);

function ChatSession({ thread, history }: { thread: Thread; history: RunHistory[] }) {
  const queryClient = useQueryClient();
  const [state, setState] = useState<ChatState>(() => chatFromHistory(history));
  const [model, setModel] = useState(thread.model);
  const [activeRunId, setActiveRunId] = useState<string | null>(
    () => history.find((run) => ACTIVE.has(run.status))?.id ?? null,
  );

  useEffect(() => {
    if (!activeRunId) return;
    return subscribeRun(activeRunId, (event) => {
      setState((current) => applyEvent(current, event));
      if (event.type === "run.finished") setActiveRunId(null);
    });
  }, [activeRunId]);

  const send = async (text: string) => {
    setState((current) => ({
      ...addUserMessage(current, `user-${Date.now()}`, text),
      running: true,
    }));
    try {
      const run = await api.startRun(thread.id, text, model);
      setActiveRunId(run.id);
      void queryClient.invalidateQueries({ queryKey: ["threads"] });
    } catch (error) {
      setState((current) => addError(current, `err-${Date.now()}`, String(error)));
    }
  };

  return (
    <div className="flex h-full flex-col">
      <header className="flex items-center justify-between border-b border-gray-200 px-4 py-2">
        <h1 className="truncate font-medium">{thread.title || "新会话"}</h1>
        <ModelSelect value={model} onChange={setModel} />
      </header>
      <main className="flex-1 overflow-y-auto px-4 py-4">
        <MessageList items={state.items} />
      </main>
      <footer className="border-t border-gray-200 p-3">
        <Composer disabled={state.running} onSend={(text) => void send(text)} />
      </footer>
    </div>
  );
}

export function ChatView({ thread }: { thread: Thread }) {
  const history = useQuery({
    queryKey: ["history", thread.id],
    queryFn: () => api.history(thread.id),
    staleTime: Infinity,
  });
  if (history.isError)
    return <p className="p-4 text-red-600">历史加载失败：{String(history.error)}</p>;
  if (!history.data) return <p className="p-4 text-gray-500">加载中…</p>;
  return <ChatSession key={thread.id} thread={thread} history={history.data} />;
}
```

```python
async def test_v6_local_embedding_dims_and_speed() -> None:
    settings = get_settings()
    headers = {"Authorization": f"Bearer {settings.litellm_master_key.get_secret_value()}"}
    async with httpx.AsyncClient(
        base_url=settings.litellm_base_url, headers=headers, timeout=120
    ) as client:

        async def embed(texts: list[str]) -> dict[str, Any]:
            resp = await client.post("/v1/embeddings", json={"model": EMBED, "input": texts})
            resp.raise_for_status()
            body: dict[str, Any] = resp.json()
            return body

        warmup = await embed(["预热"])

        latencies = []
        for _ in range(5):
            start = time.perf_counter()
            await embed(["今天下午三点和产品经理开会讨论需求"])
            latencies.append(time.perf_counter() - start)
        median_ms = statistics.median(latencies) * 1000
        print(f"V6 单条查询中位耗时：{median_ms:.0f} 毫秒")

        for _ in range(10):
            await embed([chunk] * 30)
        batch_seconds = time.perf_counter() - start
        print(f"V6 300 个片段耗时：{batch_seconds:.1f} 秒")

        assert median_ms < 300
        assert batch_seconds < 60
```
